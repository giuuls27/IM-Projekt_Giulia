Beschreibung:
SHUTTERLIGHT ist eine Web-App die Sonnenauf- und untergangszeiten für beliebige Orte weltweit anzeigt. Fotografen und Outdoor-Liebhaber können so den perfekten Moment für ihr nächstes Foto planen.

APIs:

1. Ortsname -> Koordinaten: `https://nominatim.openstreetmap.org/search?q={ort}&format=json`

2. Sonnenzeit inkl. Dämmerung: `https://api.sunrise-sunset.org/json?lat={lat}&lng={lng}&formatted=0`

Features die die Website bietet:

- Ortssuche für beliebige Orte weltweit
- Anzeige von Morgendämmerung, Sonnenaufgang, Sonnenuntergang und Abenddämmerung
- Detail-Infos pro Tageszeit mit Fotografie-Tipps
- Tagesverlauf-Balken mit animierter Sonnen-Position
- Lottie-Animation auf der Startseite
